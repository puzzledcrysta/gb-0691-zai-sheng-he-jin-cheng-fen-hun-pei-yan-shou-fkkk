# 数据定义

元素质量按物料净重×含量汇总；干湿基转换，低于检出限给上下界，不可把未检出当零，配方版本锁定。

输入字段：lot, batch, mass, unit, moisture, element, assay, basis, revision。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

Cu和Zn目标区间为V1教学配方，不外推为生产工艺。缺测元素贡献范围按0–100%计；湿基换干基先除以干物质比例；样例存在只测单元素的料批，因此验收可能待补测。

混配按batch炉次独立计算；同一lot可在不同炉次出现，采信键为(batch,lot,element)，移除批次的试算也仅影响所属炉次。

## 截单放行（M8）

牌号规格显式声明于 `app/domain.py` 的 GRADES：高牌号 Cu 8~11%、Zn 4~6%；低牌号 Cu 7.5~12.5%、Zn 3~7%，高牌号区间嵌套于低牌号之内。判定一律使用 M5 的完整含量区间[下界,上界]对照限值，不取下限或上限单点：整区间在限值内为合格，整区间在外为不合格，跨界为待确认；牌号汇总时任一元素不合格即不合格，否则任一待确认即待确认。待确认意味着补测后仍可能合格，任何待确认牌号都不得直接放行。

订单字段：order_id,grade,batch,cutoff。cutoff 为 ISO8601 UTC；判定时刻 now 缺省取当前UTC，补测完成时刻 = now + retest_hours（默认8小时）。每炉次输出决定（放行/等补测/不能放行）、放行牌号与逐条依据，依据包含元素区间与限值数值、订单截单状态、补测完成是否赶得上截单。

裁决优先级：高牌号合格且有未截单高牌号订单时优先高牌号；低牌号合格而高牌号待确认时，补测不晚于低牌号截单则等补测以保留高牌号机会，补测晚于低牌号截单则按低牌号放行以免错过；无合格牌号可放行时，仅当存在待确认且补测赶得上截单的订单才等补测，否则不能放行。

放行单存于 releases 表，batch 列 UNIQUE 保证一炉次仅一份放行单，idem_key 列 UNIQUE 保证客户端重试不新增；两人对同一炉次提交不同牌号时，先提交者生效，后者收到 RELEASE_CONFLICT（409）。
